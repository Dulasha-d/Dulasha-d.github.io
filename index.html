Enterprise Meal Management System (EMMS)

Mobile & Web Application Project · Flutter, Firebase

Mobile & web project

Overview

EMMS is a cloud-based system that replaces an organization's manual meal-planning process. Employees reserve meals before set deadlines, kitchen staff see live meal counts and update preparation status, and administrators manage staff, menus, visitor meals and audit reports. All roles stay in sync in real time across mobile and web.

System areas

  • Role-based login for employees, kitchen staff and administrators using Firebase Authentication
  • Employee portal: daily meal selection for breakfast, lunch and overtime dinner with time-based deadlines, order cancellation, order history and a monthly salary-deduction report
  • Kitchen dashboard: live production counts and meal status updates (Preparing / Ready)
  • Admin console: staff and menu management, visitor meal logging, overtime tracking, and company expense and staff deduction reports
  • Real-time synchronisation across all roles with Cloud Firestore and a daily 11:00 PM business cycle

Technology stack

Flutter Dart Firebase Authentication Cloud Firestore Firebase Storage

Inventory System

Desktop Application Project · Java, MySQL

Desktop project

Overview

Inventory System is designed to help a small shop or business manage its stock, customers and sales in one place. Staff can log in securely, keep product records up to date, create customer orders, and view past orders and bills.

System areas

  • Secure login and home dashboard
  • User management for adding and editing system users
  • Category and product management with stock quantity, price and description
  • Customer management with contact details

  • View Orders page for checking order history

Oceana Shop

Desktop Application Project · C#, Windows Forms

Desktop project

Overview

Oceana Shop is a Windows desktop application for a small cosmetics and accessories shop. It opens with a welcome screen and secure login, then takes staff through a loading screen into a main menu from which they can browse product categories and calculate customer bills.

System areas

  • Welcome screen with a Login option and Exit button
  • Secure login screen with username and password check
  • Loading/splash screen with a progress bar before entering the main menu
  • Main menu with navigation to four sections
  • Product catalog screens showing items with pictures (jewelry, hair accessories, etc.)
  • Billing screen that calculates the price for a selected item and quantity (lipstick, earrings, necklace, bangle, eye shadow palette, hair clip, hair band, nail polish, scrunchies)
  • Loyalty member option that applies a small gift/reward on checkout

Technology stack

C# (Windows Forms GUI) .NET Framework 4.5.2 Visual Studio IDE
